* ## Application Description
This project implements a practical **Student Registration and Grading System** using Oracle PL/SQL. It tracks students, course registrations, and academic performance. The implementation demonstrates required advanced PL/SQL concepts including:
* User-defined records and `%ROWTYPE` declarations.
* Nested tables.
* Implicit cursors and cursor attributes (`SQL%ROWCOUNT`, `SQL%FOUND`, `SQL%NOTFOUND`).
* Explicit cursors with `OPEN`, `FETCH`, and `CLOSE`.
* Bulk processing using `BULK COLLECT` and `FORALL` with `SAVE EXCEPTIONS`.
* Stored procedures and functions with comprehensive exception handling
*  `TOO_MANY_ROWS`, custom errors via `RAISE_APPLICATION_ERROR`)
